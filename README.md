# Xprinter Quick Print

**[Скачать установщик для Windows x64](https://github.com/Holymoly322/xprinter-quick-print/releases/latest/download/XprinterQuickPrint_Setup.exe)** · [Portable ZIP](https://github.com/Holymoly322/xprinter-quick-print/releases/latest/download/XprinterQuickPrint_Portable.zip) · [Страница установки](https://holymoly322.github.io/xprinter-quick-print/) · [Все версии](https://github.com/Holymoly322/xprinter-quick-print/releases)

Установите приложение, выберите свой принтер, перетащите PDF и задайте количество копий. Rust и инструменты разработчика не нужны. Обычная печать отправляется через Windows без дополнительных диалогов.

При первом запуске выбран встроенный **JOPA — 44×23 мм**, «Вписать полностью», без дополнительных полей и смещений. Для существующей установки можно [скачать JOPA](https://github.com/Holymoly322/xprinter-quick-print/releases/latest/download/label-44x23.json) и добавить кнопкой «Импорт». Также доступен HH 40×24 мм с полями по 1 мм слева/справа. Выбирайте пресет под свою ленту и драйвер.

Сборки пока без цифровой подписи. Контрольные суммы доступны в [SHA256SUMS.txt](https://github.com/Holymoly322/xprinter-quick-print/releases/latest/download/SHA256SUMS.txt). Для печати необходим совместимый драйвер вашей модели Xprinter. Проверка на другом компьютере и чистой Windows пока не выполнялась.

Нативное приложение Rust + Slint для печати PDF-этикеток через установленный Windows-драйвер. Целевая архитектура — Windows x64. Windows 10/11 входят в целевой диапазон; проверка на чистых компьютерах и физическом принтере описана в TEST_REPORT.md.

## Использование

1. Запустите приложение. В мастере выберите установленную очередь либо добавьте принтер штатным мастером Windows. Можно пропустить настройку и работать с PDF без принтера.
2. Откройте PDF кнопкой или перетащите его в окно.
3. Выберите принтер и пресет. При первом запуске выбран JOPA — 44×23 мм, «Вписать полностью», нулевые поля, поворот и смещения. Для другой ленты есть HH — 40×24 мм с полями слева/справа по 1 мм. Обновление сохраняет существующие пресеты; добавить JOPA в старую конфигурацию можно импортом.
4. «Изменить пресет» открывает отдельный редактор с живым превью. Задайте размер, масштаб, поворот, поля, смещение и калибровку. «Как новый» создаёт пресет; название редактируется там же.
5. Счётчик начинается с 0. Кнопки +25, +50 и +100 прибавляют указанное количество при каждом нажатии; «Сброс» возвращает 0. Для печати задайте 1–9999 копий и при необходимости страницы: `1-3,5`. Пустое поле означает все страницы.
6. Нажмите «ПЕЧАТЬ». Обычная отправка не открывает DocumentProperties, Acrobat или браузер. Статус «Передано в очередь» не означает подтверждения физического выхода этикетки.

Превью использует тот же расчёт миллиметров и размещения, что печать. Это не обещание идентичности физическому выходу: аппаратные поля, датчик, калибровка, плотность и механика зависят от драйвера и принтера. Параметры нельзя угадывать по названию Xprinter. Если драйвер не принимает размер бумаги или одну копию, отправка прекращается с ошибкой.

## Пресеты и драйвер

Поддержаны исходный масштаб 100%, Fit, Fill, произвольный процент; 0/90/180/270°; четыре поля; центрирование; смещение и поправка калибровки. Fit сохраняет пропорции. Fill обрезает за полями. Альбомный формат задаётся шириной больше высоты, поворот содержимого независим.

«Настроить через драйвер и сохранить» — единственное намеренное открытие окна драйвера. Снимок содержит public/private DEVMODE, очередь, имя, окружение и версию драйвера. Он восстанавливается только при совпадении идентификаторов и проверке структуры. Размер бумаги, поворот содержимого и количество копий остаются под управлением приложения. Именованные фирменные профили не перечисляются: это не стандарт Windows API. Снимок также привязан к MachineGuid компьютера; перенос Portable-конфигурации на другой ПК не разрешает его восстановление. После обновления драйвера захватите снимок заново. Импорт JSON удаляет частные снимки; их следует создавать на компьютере назначения.

Скорость, плотность и датчик не представлены как универсально доступные настройки. Настраивайте их в фирменном драйвере. Windows может не предоставлять достоверный статус отключённого USB/сетевого устройства.

## Очередь

«Добавить в очередь» фиксирует текущие PDF, принтер, пресет, копии и страницы. Выберите элемент в списке, переместите стрелками или удалите. «Применить настройки» назначает выбранному элементу текущие параметры. «Печать очереди» отправляет задания последовательно в фоне; при ошибке оставшаяся часть помечается отменённой. Отправленные задания не отзываются автоматически. История последних 200 результатов хранится отдельно.

При выборе нескольких PDF все выбранные файлы добавляются в очередь. При перетаскивании каждый PDF также добавляется в очередь; её можно раскрыть кнопкой «Очередь». PDF можно перетаскивать в окно. Масштаб и перетаскивание превью не меняют печатный масштаб — его задаёт пресет.

Горячие клавиши: Ctrl+O, Ctrl+P, Ctrl+Plus, Ctrl+Minus, Ctrl+0; Ctrl+S в редакторе; Delete удаляет выбранный элемент очереди. Горячие клавиши зависят от фокуса: при вводе текста стандартные действия поля имеют приоритет.

## Установка драйвера

«Настроить принтер» доступно повторно. Проверки очередей, зарегистрированных драйверов и явных PnP-кандидатов выполняются отдельно. Неизвестная модель автоматически не выбирается. Сетевой принтер может отсутствовать в USB/PnP-инвентаризации.

Основной путь — штатный мастер добавления принтера и Windows Update. Если модель не найдена, используйте официальный раздел поддержки производителя для точной модели и Windows x64. Приложение не содержит INF-пакетов и не скачивает неизвестные драйверы. Административные действия выполняет штатный мастер с собственным UAC; приложение запускается без повышения прав.

Отсутствие очереди не доказывает отсутствие пакета драйвера. Наличие зарегистрированного драйвера не доказывает, что очередь настроена. После установки обновите список, выберите очередь и проверьте доступ. Пробная печать возможна только по явной кнопке пользователя.

## Данные

Установленная версия: `%APPDATA%\XprinterQuickPrint\` — `settings.json`, `presets.json`, `history.json`, `logs/`. Portable: `portable.flag` рядом с EXE включает `config/` рядом с программой. Каталог должен быть доступен для записи. Не распаковывайте Portable в Program Files.

Запись JSON выполняется через временный файл, Flush/sync и MoveFileEx(REPLACE_EXISTING | WRITE_THROUGH). Предыдущая версия сохраняется как `.json.bak`. Настройки v0 мигрируются в v1; будущие неизвестные версии отклоняются без перезаписи. Повреждённый файл не заменяется молча пустыми данными: восстановите резервную копию.

При обновлении пресеты сохраняются. Деинсталляция не удаляет драйверы и очереди; удаление пользовательских настроек — отдельный вопрос с ответом «Нет» по умолчанию.

## Сборка MSVC

Требуется только разработчику: Rust stable x64 MSVC с rustfmt/clippy; Microsoft C++ Build Tools с Windows SDK; Inno Setup 6; cargo-about 0.8.2 (`cargo install cargo-about --version 0.8.2 --locked`).

```
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo build --release --locked
build_portable.bat
build_installer.bat
```

`build.bat` собирает EXE и проверяет закреплённый архив PDFium. `scripts/prepare-runtime.ps1` загружает только x64 no-V8/no-XFA PDFium chromium/7725 с фиксированным SHA-256 и проверяет его перед распаковкой. Это сборка проекта bblanchon/pdfium-binaries, не официальный бинарник Google. Полные notices сохраняются. В runtime нет Node/Python/веб-сервера.

Результаты: `dist/XprinterQuickPrint_Portable.zip`, `dist/XprinterQuickPrint_Setup.exe`. Установщик не подписан. EXE, pdfium.dll и уведомления о лицензиях распространяются вместе; Rust, Cargo, Visual Studio и Inno Setup пользователю не нужны. После установки подключение к интернету приложению не требуется; Windows Update для установки отсутствующего драйвера может потребовать интернет.

Workflow `.github/workflows/windows-release.yml` выполняет форматирование, clippy, тесты, release, сбор лицензий, Portable и Inno Setup. Он публикует артефакты, но не утверждает наличие цифровой подписи.

## Архитектура

`layout.rs` — чистая геометрия в мм; `pdf.rs` — PDFium и растровое размещение; `printing.rs` — изолированная ABI-граница GDI/spooler с RAII; `queue.rs` — проверка заданий и mockable Backend; `drivers.rs` — Windows setup и инвентаризация; `storage.rs` — JSON/миграции; `app.rs` — координатор UI и фонового потока; `ui/main.slint` — окна. Тяжёлые операции не обращаются к Slint из чужого потока: UI принимает события таймером.

GDI-путь: EnumPrinters → OpenPrinter → DocumentProperties → CreateDC → проверка размера/DPI → PDFium/layout → StartDoc → StartPage/StretchDIBits/EndPage → EndDoc. Drop освобождает DC/принтер и вызывает AbortDoc при незавершённом задании. Исходный PDF не отправляется RAW. Драйвер получает одну копию; приложение повторяет последовательность страниц, предотвращая двойное размножение.

## Тестирование

Обычный `cargo test` не печатает и не требует DLL PDFium. Отдельный игнорируемый `pdfium_runtime` проверяет настоящую PDF-фикстуру и формирует PNG; для него требуется DLL рядом с тестовым EXE. Команда и фактические результаты приведены в TEST_REPORT.md. Тестирование физического принтера выполняется вручную: 1, затем 10 копий одностраничного PDF, многостраничный диапазон, Fit/Fill, все повороты, обновление драйвера, отключение устройства и перезапуск приложения.

Лицензии: код MIT; Slint Royalty-free 2.0 (виджет AboutSlint в «О программе»); PDFium и остальные компоненты — см. THIRD_PARTY_NOTICES.md, THIRD_PARTY_LICENSES.html и каталог pdfium-licenses в дистрибутиве.

## Локальная сборка без MSVC

`build_gnu.bat` использует Rust stable 1.99.1 GNU и закреплённый LLVM-MinGW 20261104 UCRT x64 из релизов mstorsjo с SHA-256. Файлы инструментов находятся в `.tools/`, не устанавливаются системно и не входят в дистрибутив. Перед запуском установите GNU toolchain: `rustup toolchain install stable-x86_64-pc-windows-gnu --profile minimal --component rustfmt --component clippy`. Если stable уже изменился, используйте указанный в скрипте номер версии. Скрипт останавливается при несовпадении версии. Артефакт получается тем же Windows x64 EXE; при упаковке проверьте его DLL-импорты.

Кнопка «Создать» открывает новый пресет, «По умолчанию» явно задаёт пресет следующего запуска; без явного выбора восстанавливается последний. Окно «История» показывает результаты последних 200 заданий. «Отменить передачу» проверяется между страницами и вызывает AbortDoc для незавершённого документа; уже принятые задания в очереди Windows не отзываются. Заблокированный вызов драйвера может задержать отмену.

Менеджер пресетов открывается кнопкой «Управление» рядом с выбором пресета. Количество копий и кнопка печати остаются видимыми; подробная очередь раскрывается отдельно. Рамка и пунктир в превью — вспомогательные линии, в печать они не отправляются. Оранжевый пунктир обозначает поля пресета, а не подтверждённую границу аппаратной печатной области.

`cargo test` дополнительно отрисовывает реальные Slint-компоненты без системного окна и сохраняет `ui-main-dark.png`, `ui-main-light.png`, `ui-preset-editor.png`, `ui-printer-setup.png`. Эта проверка использует PDFium-растеризованную тестовую фикстуру и не заменяет интерактивный тест Windows-окна. Обычное приложение всегда открывает PDF через PDFium; фикстура не используется в рабочем интерфейсе.

## Ярлыки и обмен пресетами

Установщик создаёт ярлык в меню «Пуск» и по умолчанию предлагает ярлык рабочего стола. Для Portable откройте «О программе» → «Создать ярлыки»: ярлыки рабочего стола и «Пуска» будут ссылаться на текущий EXE. После переноса папки создайте их повторно.

Кнопки «Импорт» и «Экспорт» находятся рядом с выбранным пресетом. Экспорт сохраняет выбранный пресет в JSON; импорт добавляет пресеты к имеющимся. Поддерживаются новый формат с версией 1, старый массив пресетов и отдельный пресет. Частные снимки драйвера при обмене удаляются: на другом устройстве настройте драйвер заново.
## Очередь с паузами

«Печать очереди» передаёт только один элемент очереди за раз. Партия — один PDF со всеми выбранными страницами и указанным количеством копий. После передачи партии программа ждёт: оторвите ленту и нажмите «Продолжить» для следующего элемента.

Поле «Минимальная пауза, с» задаёт задержку 0–300 секунд (по умолчанию 5, значение сохраняется). Отсчёт начинается после передачи задания в Windows, а не после подтверждения выхода бумаги. Пока идёт отсчёт, «Продолжить» недоступна. После отсчёта автоматической отправки нет — требуется нажатие.

Чтобы печатать 100 копий порциями по 25, добавьте PDF в очередь четыре раза по 25 копий. У каждой строки есть собственный счётчик копий. «Копии всем» применяет текущее количество ко всем ещё не переданным элементам.

«Остановить очередь» отменяет дальнейшую передачу. Уже переданные задания остаются в очереди Windows. При ошибке оставшиеся элементы не отправляются. Следующая «Печать очереди» пропускает уже переданные строки. Для повторной печати добавьте новую строку. Обычная кнопка «ПЕЧАТЬ PDF» передаёт выбранный PDF и отмечает совпадающую выбранную строку очереди переданной.

Версия 0.4.1 сохраняет коды форматов бумаги, полученные от драйвера через DeviceCapabilities, включая коды от 256. При совпадении размеров используется формат драйвера. Для размеров без совпадения задаётся пользовательский формат с явными шириной и высотой.
