# Отчёт проверки — 7 ноября 2026

Последняя версия — 0.4.2. Локально успешно завершены fmt, Clippy с запретом предупреждений, 30 автоматических тестов, Release и изолированная проверка установщика. Пользователь сообщил, что результат ручной печати 0.4.1 на XP-365B его устраивает. Проверка на другом ПК и чистой Windows не выполнена. Ниже сохранена хронология предыдущих проверок с ограничениями на момент их выполнения.

- Rust stable 1.99.1, Windows x64 GNU; Slint 1.14.1, pdfium-render 0.8.35, windows 0.58.0.
- `cargo fmt --check` — успешно.
- `cargo clippy --locked --all-targets -- -D warnings` — успешно.

- Отдельный тест Slint-компонентов без системного окна — успешно; снимки повторно проверены после исправления viewport и компоновки: обе темы, редактор и мастер настройки. Количество копий и кнопка печати видны, этикетка не обрезается в режиме «Вписать». PNG являются результатом рендеринга настоящего дерева компонентов, а не макетом приложения.
- Отдельный `pdfium_runtime` — успешно (8,90 с в debug): настоящий PDF 100 × 150 мм открыт PDFium, проверены размеры и наличие содержимого, создан PNG этикетки 40 × 30 мм.
- Отдельный `virtual_pdf_backend` — успешно (102,54 с в debug): GDI отправил задание в **Microsoft Print to PDF**, выходной PDF содержит ровно две страницы с изображением этикетки. Физический принтер не использовался. После уточнения преобразования DPI повторный тест также прошёл (106,93 с в debug), снова получены ровно две страницы.
- Предыдущая сборка 0.1.0: Release EXE 13 126 144 байт (11 мин 28 с).
- Проверены PE-импорты приложения и PDFium: только системные DLL Windows/UCRT. Нет зависимости от установленного Rust, Cargo, Visual Studio или отдельного Visual C++ Redistributable.
- PDFium-архив проверен SHA-256 по digest релиза. Cargo.lock и версии инструментов закреплены. Получение Inno Setup в CI — официальный релиз с фиксированным SHA-256.
- Сформированы THIRD_PARTY_LICENSES.html, Slint-LICENSE.md, PDFium notices и LLVM runtime notices. Slint выбран под Royalty-free 2.0 с виджетом AboutSlint в «О программе».

## Команды

Локальный компилятор MSVC недоступен: установка Build Tools завершалась 1602, явный UAC-запуск был отменён Windows. Поэтому фактическая локальная сборка использовала GNU/LLVM-MinGW:

```
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-gnu.ps1 -Mode Release
```

PDFium и виртуальный GDI тестируются отдельно от обычного cargo test. DLL помещается рядом с `target/debug/deps/runtime-*.exe`, затем тестовый EXE запускается из корня проекта:

```
<runtime-test-exe> pdfium_runtime --ignored --exact --nocapture
<runtime-test-exe> virtual_pdf_backend --ignored --exact --nocapture
```

Второй тест жёстко использует имя Microsoft Print to PDF и передаёт путь выходного файла через DOCINFO. Повторный запуск не перезаписывает существующий результат без отдельного решения пользователя/разработчика. Обычный cargo test оба теста пропускает.

## Не проверено и ограничения

- Физический Xprinter отключён; пробной физической печати не было. Нельзя утверждать, что проверены датчик, плотность, скорость, реальные поля, подача и конкретная модель драйвера.
- Превью показывает геометрию пресета. Аппаратное обрезание выполняет драйвер/GDI; подтверждение размеров и DPI перед печатью не заменяет физическую калибровку.
- Снимки DEVMODE проверяются по компьютеру, очереди, имени/окружению/версии драйвера, public/private размеру и версии структуры. Реальное фирменное окно неизвестного Xprinter и его именованные профили не тестировались. Частные снимки очищаются при импорте и могут быть явно удалены в редакторе.
- Модель и INF-пакет неизвестны. Пакет производителя не включён и автоматически не устанавливается. Реализован безопасный путь через мастер Windows/Windows Update с ручным выбором модели и возможностью пропуска.
- Управление реальным Windows-окном через computer-use было отклонено автоматической проверкой доступа: `Computer Use was not approved to use xprinter-quick-print`. Поэтому интерактивные клики, Drag & Drop и горячие клавиши в нативном окне не объявляются пройденными. Отдельно проверены компиляция обработчиков и программная отрисовка Slint без системного окна.
- Чистая Windows 10/11 VM и другой компьютер не использовались. Совместимость Windows x64 предусмотрена сборкой и системными API; архитектуры ARM/x86 не заявляются.
- GitHub Actions подготовлен, но workflow не запускался в GitHub в этой сессии.
- Кодовая подпись не настроена; приложение и установщик не следует считать подписанными.
